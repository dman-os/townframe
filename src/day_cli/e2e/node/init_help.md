# `day init --help`

```console
$ day init --help
Set up a new node directory with a fresh identity

Usage: day init [OPTIONS] [DIR]

Arguments:
  [DIR]  The directory to create the node in (default: the --node directory)

Options:
      --node <DIR>  The node's directory [env: DAY_NODE=node]
  -h, --help        Print help

```
