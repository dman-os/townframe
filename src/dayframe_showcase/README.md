# Design showcase

Native Dioxus theme lab for shared `ui` foundations, deterministic design fixtures, and primitive component specimens.

```sh
deno run --allow-all x/dayframe.ts showcase
```

`DAYFRAME_SHOWCASE_KIT=<group>` (`nav`, `sections`, `list`, `sheet`) shows only that group of
`clay_dioxus_kit` specimens. The native window cannot be scrolled by automation, so a screenshot
run captures one group at a time (see `.agents/skills/dayframe-native-dev-loop`).
