- **2026-11-17, morph review** (`github.com/r/morph` v0.48, read by me). It wraps git, mirrors commits into its own store, and records a session as a Run + flat Trace (Claude Code hook events cut to 2,000 chars). A commit links to a run only through `morph commit --from-run` or a fresh test-run breadcrumb, so a plain `git commit` or jj gets none. Rewrites get a `rewritten` annotation (old → new from `post-rewrite`) and nothing carries over. The sha → morph lookup walks every branch, then every commit, per call. "Human edits" is per file at `morph commit`: the agent's last claimed content against the staged blob. It's broken for Claude Code (the hook stores tool-input JSON in a field the comparison skips, and the edit-tool list uses Cursor's names). Worth taking: per-commit test metrics (D11), exact rewrite pairs from `post-rewrite` (in `intxt-commit-membership.md`), and the human-edit view (ours from cause-less ops, line-level).
